About CampusHub

CampusHub is a centralized web-based platform designed to simplify daily campus operations. It connects students, faculty, and staff into a single interface, providing tools for room booking, event management, maintenance requests, study material sharing, and campus-wide notices.

This project demonstrates a real-world, fully functional campus management solution built using Django, TailwindCSS, and modern design principles. It is developed as a portfolio-ready project to showcase both backend and frontend capabilities.
